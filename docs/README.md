# docs/

Audit and design notes from earlier project phases (written while the work was in progress, so statements about the test split describe the project at that time; see the main README for the current statement). They are not needed to reproduce the final results.

- `notebook4b_audit.md` : audit of the class-weight experiments, including the 3-seed replication that measured the run-to-run noise floor of ROC-AUC and PR-AUC on the validation set.
- `phase0_audit_v2.md` : read-only audit of the Version 2 (disc-focused crop) plan against the real data and notebooks.
- `version2_disccrop_design_note.md` : design note for building the disc-focused cropped dataset.
- `version2_edge_policy.md` : pre-registered rule for how crops are handled at image edges.
